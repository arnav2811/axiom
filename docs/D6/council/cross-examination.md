## Cross-Examination of Findings

### Challenge 1: Arnav's A4 (Design Principles Alignment)

**Keshav:** Arnav, you noted that the D6 report doesn't explicitly connect features to all 5 design principles. But the architecture document does reference DP1 through factor badges and DP2 through coaching constraints. Isn't this sufficient?

**Arnav:** The architecture document mentions these connections, but the main D6 report — which is what markers read first — should have a clear mapping table. D2 established 5 design principles (DP1 Transparent Provenance, DP2 Constraint-Aware Protection, DP3 Low-Burden Navigation, DP4 Communal Boundary Integrity, DP5 Descriptive Circularity). Sprint 3 addresses all five, but only DP1 and DP2 are explicitly named.

**Resolution:** Accept recommendation. A brief design principles table could strengthen the report. However, this is a minor enhancement — the evidence exists across documents. **Non-blocking.**

### Challenge 2: Keshav's K5 (Sprint Velocity)

**Arnav:** Keshav, you observed that 100% velocity across all 3 sprints may appear unrealistic. Should we have intentionally left some stories incomplete?

**Keshav:** No — fabricating incomplete work would be dishonest. The 100% velocity reflects that our sprint planning was conservative (28-30 SP with 2 team members). The daily burndown shows natural variance. The key is that scope was constrained to match capacity.

**Resolution:** No change. The velocity data is consistent with a small team doing careful estimation. **Agreed.**

### Challenge 3: TestFX Deferred

**Arnav:** We've deferred TestFX integration across all three sprints. This means UI testing is entirely manual. Is this a risk for the D7 evaluation?

**Keshav:** TestFX is a nice-to-have, not a must-have. The rubric asks for "testing" not "UI automation testing." Our 28+ unit and integration tests plus manual UI verification meet the criterion. For D7, participants will interact with the actual UI — that IS the evaluation.

**Resolution:** TestFX remains deferred. Manual UI testing is acceptable for assessment scope. **Agreed.**
