### Key D2 Content Summary

**Selected Concept:** Concept A — Contextual Choice Coach (Footprint Lens)

**Design Principles:**
1. DP1: Transparent Provenance — every estimate exposes formula, factor, source, year, geography
2. DP2: Constraint-Aware Protection — protected routines get no punitive advice
3. DP3: Low-Burden Navigation — ≤3 primary decisions, ≤60 seconds, reversible
4. DP4: Communal Boundary Integrity — shared utilities as collective totals only
5. DP5: Descriptive Circularity — record repair/reuse without fabricated offsets

**Interaction Model:** P0 (Onboarding) → P1 (Activity Entry) → P2 (Results Dashboard) → P3 (Assumptions Inspector) → P4 (Action Coach) → P5 (Circular Habits Record) → P6 (Household Boundary View)

**Activity Categories:** Electricity, Travel, Food, Water, Packaging, Waste, Repair/Reuse

**Technical Direction:** Java + JavaFX desktop, local CSV persistence, zero telemetry
