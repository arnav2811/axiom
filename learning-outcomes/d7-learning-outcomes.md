# D7 Learning Outcomes

## Module Learning Outcomes Addressed

### LO1: Apply software engineering principles in a team project
- **Evidence:** Complete evaluation protocol developed collaboratively. Materials distributed between team members (Arnav: facilitation/analysis; Keshav: instruments/observation). Council review applied to evaluation deliverables.
- **Files:** `docs/D7/d7-report.md`, `docs/D7/contribution-plan.md`

### LO2: Use Agile SCRUM methodology
- **Evidence:** Evaluation preparation followed sprint-like planning with daily check-ins. Materials produced iteratively with internal review. Meeting minutes document preparation workflow.
- **Files:** `simulated-and-reconstructed/meeting-minutes/d7-phase-minutes.md`

### LO3: Design, implement, and test software to meet requirements
- **Evidence:** Evaluation tasks map directly to implemented features. Task success criteria verify that requirements are met from a user perspective. This closes the loop from D1 requirements → D3 design → D4-D6 implementation → D7 evaluation.
- **Files:** `docs/D7/evaluation-materials/task-cards.md`, `docs/D7/d7-report.md` §4

### LO4: Evaluate software quality
- **Evidence:** Think-aloud usability testing with SUS and SEQ provides multi-dimensional quality assessment. Success criteria define quantitative thresholds. Analysis plan includes severity rating for identified issues.
- **Files:** `docs/D7/d7-report.md` §5-§6, `docs/D7/analysis-plan.md`

### LO5: Reflect on professional practice
- **Evidence:** Individual reflections on evaluation design experience, mixed-methods learning, and project-wide growth. Council review identifies improvement areas.
- **Files:** `simulated-and-reconstructed/reflection-drafts/Arnav_D7.md`, `simulated-and-reconstructed/reflection-drafts/Keshav_D7.md`

## Key Skills Developed in D7
1. **User-centred evaluation design** — Selecting and justifying appropriate evaluation methods
2. **Instrument design** — Creating valid, reliable measurement instruments (SUS, SEQ, observation sheets)
3. **Research ethics** — Ensuring UK GDPR compliance, informed consent, and data protection
4. **Mixed-methods analysis** — Combining quantitative metrics with qualitative coding
5. **Academic writing** — Structuring an evaluation report with proper referencing
